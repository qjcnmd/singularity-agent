crates/ 结构

crates/
├── protocol/                                             # RPC 契约：前后端共享的类型定义（13 .rs）
│   ├── examples/                                         # 命令行导出前端 TypeScript 契约
│   │   └── export_types.rs                               # 运行导出 protocol.generated.ts 到 apps/desktop/src/
│   │       └── main()                                    # 调用 protocol::typescript::client_types()
│   └── src/                                              # 共享契约定义（12 文件）
│       ├── lib.rs                                        # re-export 全部 DTO 模块、RpcRequest 及可选 typescript 导出器
│       ├── rpc.rs                                        # 前后端 JSON-RPC 方法总表、共享 MessageInput 与 21 个请求参数体
│       │   ├── RpcRequest                                # Workspace/Session(含 changedFiles/fileDiff/rewind)/Model/Mcp/Skill 分发
│       │   ├── EmptyParams                               # 无参 RPC 请求
│       │   ├── WorkspaceAddParams                        # 新增工作区路径参数
│       │   ├── SessionFocusParams                        # 同步当前聚焦会话以过滤非聚焦高频进度
│       │   ├── SessionStartParams                        # 新任务初始化与禁用上下文模块参数
│       │   ├── MessageInput                              # 提交与回溯共用的拍平输入载荷（text / images / files / annotations）
│       │   ├── SessionTextParams                         # 已有任务继续发送参数（拍平 MessageInput）
│       │   ├── SessionChangedFilesParams                 # 项目工作区 Git 改动文件查询参数（必传 workspaceRoot，直返 Vec<ChangedFile>）
│       │   ├── SessionFileDiffParams                     # 项目单文件 Git 差异查询参数（必传 workspaceRoot 与 path）
│       │   ├── SessionRewindParams                       # 对话历史按用户消息 ID 截断并拍平必填 MessageInput 立即重发参数
│       │   ├── ProviderSaveParams                        # 保存模型提供方与变体配置参数
│       │   ├── WebSearchSaveParams                       # 保存联网搜索 API 地址与脱敏密钥参数
│       │   └── DiscoverModelsParams                      # 在线拉取提供方 /models 请求参数
│       ├── typescript.rs                                 # Rust → TypeScript 类型声明编译器
│       │   ├── Bindings                                  # add & visit 收集 RpcRequest 及关联 DTO
│       │   └── client_types()                            # 生成 DTO 声明、RpcContract、StreamEnvelope 与 RpcResponse
│       ├── app.rs                                        # 工作台引导、会话列表、运行时状态与流信封 DTO
│       │   ├── AppBootstrap                              # 启动首包：工作区、摘要、脱敏目录与 revision
│       │   ├── SessionReadResult                         # 单任务完整历史、运行时状态与 Vec<ContextModule> 结果
│       │   ├── Workspace                                 # 已注册工作区路径与规范 key
│       │   ├── ThreadSummary                             # 左侧任务列表条目摘要与运行阶段
│       │   ├── SessionPhase                              # Idle / Running / Compacting / Stopping
│       │   ├── TurnEventEnvelope                         # 带严格递增序号的流式事件信封
│       │   ├── SessionRuntime                            # 活跃回合、上下文占比、实时累计用量（model_usage）、后台任务与挂起提问快照
│       │   ├── ContextUsage                              # 当前上下文 token 占用与容量比例
│       │   ├── RedactedModelCatalog / RedactedWebSearchConfig # 隐藏真实 api_key 后的下发模型与联网搜索目录
│       │   ├── RpcError                                  # JSON-RPC 错误载荷（仅 message: String）
│       │   └── RpcResponse                               # 泛型 JSON-RPC 响应信封（供 transport 与前端共用）
│       ├── history.rs                                    # 公开历史条目、回合与累计用量口径
│       │   ├── HistoryItem                               # 正文 / 思考 / 工具 / 压缩 / 错误投影项
│       │   ├── id()                                      # HistoryItem 与实时流严格同源的条目 ID
│       │   ├── ThreadTurn                                # 按 operation_started 切分的公开用户回合
│       │   ├── TurnStatus                                # Completed / Interrupted / Failed 回合终态
│       │   ├── SessionModelUsage                         # 整条会话累计输入/输出/缓存用量
│       │   ├── ToolResult                                # 工具输出、图片附件与 unified diff 结果
│       │   └── ReadSource                                # Read 工具读取的文件起止行号范围
│       ├── ledger.rs                                     # 后端内部账本、请求观测与后台命令输出快照类型
│       │   ├── RequestPurpose / RequestObservation       # 单次生成/压缩请求的耗时、状态与用量观测
│       │   ├── ModelUsage                                # 单次模型请求 token / 缓存命中统计
│       │   ├── ProviderAttemptStatus                     # 模型请求尝试终态（Ok / Error / Cancelled）
│       │   ├── CommandOutputSnapshot                     # 命令输出尾部字节快照与溢写路径
│       │   └── BackgroundTask                            # 后端内部后台命令完整状态（含模型输出快照）
│       ├── event.rs                                      # 单回合运行期推送给前端的事件
│       │   ├── TurnEvent                                 # ContextLoaded(Vec<ContextModule>)、文本/思考增量、工具、提问与精简起止事件
│       │   └── TurnErrorDetail                           # 回合失败错误分类与诊断详情
│       ├── background.rs                                 # 前端可见后台命令状态与增量更新 DTO
│       │   ├── VisibleBackgroundTask                     # 剥离内部字段后下发前端的安全任务视图
│       │   ├── BackgroundTaskState                       # Running / Exited / Stopped / Failed / Interrupted
│       │   └── BackgroundTaskUpdate                      # 附带 SessionPhase 的后台任务状态变更推送
│       ├── question.rs                                   # ask_user_question 工具与前端提问 DTO
│       │   ├── PendingQuestion                           # 当前挂起等待用户回答的题组快照
│       │   ├── UserQuestion                              # 单个问题与可选项定义
│       │   └── QuestionAnswerParams                      # 前端回传的答案提交参数
│       ├── image.rs                                      # 图片上传与已落盘附件索引 DTO
│       │   ├── ImageAttachment                           # 已落盘附件 id 与 MIME 元数据
│       │   └── ImageUpload                               # 前端上传的 data URL 图片载体
│       ├── mcp.rs                                        # MCP 传输配置、工具列表与连接状态 DTO
│       │   ├── McpTransportConfig                        # Stdio 子进程 / HTTP 远程传输配置（Debug 隐藏原始 args）
│       │   ├── McpServerInput                            # 前端提交与脱敏回显的 MCP 服务配置
│       │   ├── McpConnectionStatus                       # NotConnected / Connecting / Connected / Failed 状态
│       │   └── McpServerState                            # 单个 MCP 服务状态、工具列表与错误详情（不附带 Token 估算）
│       └── inspection.rs                                 # 文件改动差异、技能目录、文档读写与上下文预览胶囊 DTO
│           ├── ChangedFileStatus / ChangedFile           # 文件改动状态（added/modified/deleted）与增删行数统计（changedFiles 直返 Vec）
│           ├── SessionFileDiffResult                     # session.fileDiff 返回的规范相对路径与 unified diff
│           ├── ContextModule                             # 单个上下文模块开关状态与 token 估算（直接用于预览与加载结果）
│           ├── ContextGroup                              # Instructions / Tools / Skills / Mcp 分组
│           ├── SkillMetadata                             # 技能名称、路径、作用域与简介元数据
│           └── SkillCatalog                              # 工作区下发现的技能清单
│
├── core/                                                 # 基础设施：产品身份、数据目录与项目资源（app_core，6 .rs）
│   └── src/                                              # 底层公共工具集（6 文件）
│       ├── lib.rs                                        # BOM 剥离、原子写文件、Token 估算与时间路径工具
│       │   ├── strip_utf8_bom() / strip_utf8_bom_bytes() # 统一剥离字符串/字节流 UTF-8 BOM
│       │   ├── write_bytes_atomic()                      # 同目录临时文件 + flush/sync 原子替换
│       │   ├── write_json_atomic()                       # 先序列化再调用 write_bytes_atomic 写盘
│       │   ├── estimate_tokens_of()                      # ASCII 按 1/4、非 ASCII 按 1 token 向上取整
│       │   ├── now_iso() / iso_elapsed_secs()            # UTC ISO8601 时间戳生成与秒差计算
│       │   └── display_path()                            # 去掉 Windows \?\ 长路径前缀用于展示
│       ├── identity.rs                                   # 单点产品身份、环境变量、目录名与 UA 常量
│       ├── user_home.rs                                  # ~/.singularity 或 SINGULARITY_HOME 定位
│       │   ├── resolve_home()                            # 优先 SINGULARITY_HOME，回退 ~/.singularity
│       │   └── validated_root()                          # 拒绝空白或相对路径数据根目录
│       ├── workspace.rs                                  # 项目目录规范化与 Git 根查找
│       │   ├── canonicalize_workspace()                  # 校验目录存在并返回规范 PathBuf
│       │   ├── workspace_key() / same_saved_path()       # 统一 Windows 大小写不敏感路径归类键与等价判断
│       │   └── project_root()                            # 沿父目录向上查找 .git 根目录
│       ├── project_instructions.rs                       # AGENTS.md 分层收集加载（导出 PROJECT_INSTRUCTIONS_FILE_NAME）
│       │   ├── load_agent_instructions()                 # 按 全局->project_root->cwd 读 AGENTS.md
│       │   ├── InstructionFile                           # 指令文件路径、作用域来源与正文
│       │   └── instruction_directories()                 # 列出按优先级排序的指令搜索目录
│       └── skills.rs                                     # SKILL.md 发现与全文按需读取
│           ├── SkillCatalog                              # discover() 规范路径+workspace_key 去重；model_skills() 滤禁用
│           ├── Skill                                     # load_instructions() 仅调用时读正文
│           └── discover_skill()                          # 解析 SKILL.md YAML frontmatter 元数据
│
├── model/                                                # 模型配置、纯 LLM 消息类型、协议无关客户端与编解码（19 .rs）
│   └── src/                                              # 模型层源码（19 文件）
│       ├── lib.rs                                        # 导出 ModelClient、ModelConfigManager、ProviderError、WebSearchAccess、ToolDefinition 与消息类型
│       ├── client.rs                                     # ModelClient：统一入口（provider_name/model_name），按协议分发请求
│       ├── error.rs                                      # 4 类错误分类；redact_diagnostic() / bounded_redacted_diagnostic() 截断前全量脱敏
│       │   ├── ModelErrorKind                            # Cancelled / Temporary / ContextLengthExceeded / Other
│       │   ├── ProviderError                             # is_context_overflow / is_retryable
│       │   ├── provider_error_kind_for_fields()          # 按错误码与 Messages 扩展超限模式识别上下文超限与可重试错误
│       │   └── provider_error_kind_for_http_status()     # 408 / 409 / 429 / 5xx 判 Temporary
│       ├── config/                                       # config.json 读写、选择解析与模型探测（5 文件）
│       │   ├── mod.rs                                    # validate_base_url / validate_provider_value / validate_identifier / validate_reasoning_variants
│       │   ├── manager.rs                                # ModelConfigManager：config.json 单一读写管理器（resolve_api_key 统一同源凭据复用）
│       │   │   ├── ModelConfigManager                    # open / resolve / validate_selection / redacted_catalog
│       │   │   ├── context_window()                      # 按选中模型返回上下文窗口上限
│       │   │   ├── save_provider()                       # 锁内原子替换；空 key 经 resolve_api_key 同源留旧值并清失效选中
│       │   │   ├── save_web_search() / web_search_access() # 读写 config.json 的 web_search 段并校验凭据
│       │   │   ├── remove_provider()                     # 移除提供方并回退无效默认选择
│       │   │   ├── model_definitions()                   # 校验并转换表单模型列表
│       │   │   └── discover_models()                     # 异步在线探测 /models（同源复查已存密钥，委托 discovery::discover）
│       │   ├── selection.rs                              # 选中 ID → ProviderConfig + SelectedModel
│       │   │   ├── ProviderConfig                        # 解码后的提供方 URL 与密钥
│       │   │   ├── SelectedModel                         # 当前选中模型、协议及推理档位
│       │   │   └── resolve_model_selection()             # 缺失配置、无有效变体或 max_output_tokens >= max_context_tokens 直接报错
│       │   ├── discovery.rs                              # 内部 /models 查询实现（仅解析 data 数组）
│       │   │   ├── discover()                            # pub(crate)：按协议鉴权查提供方 /models
│       │   │   ├── discovery_transport_error()           # 统一处理探测超时、取消与连接失败
│       │   │   └── discovery_http_error()                # 先收错误体再剥离敏感 URL 查询参数
│       │   └── user.rs                                   # 用户级 config.json BTreeMap 有序读写与 BOM 剥离
│       │       ├── UserConfigFile / UserConfigProvider   # 用户级 config.json 根与提供方序列化结构

│       ├── types.rs                                      # 拍平的提供方无关统一消息、工具定义与思考元数据
│       │   ├── ToolDefinition / estimate_tool_tokens()   # 内置与 MCP 共用工具 Schema 及 Token 预估
