# 工作台交互

本文维护当前界面的操作、显示与交互约定。配置和初次使用见 [安装说明](INSTALL.md)，持久事实、协议和状态所有权见 [架构图谱](singularity.md)。

## 项目与任务导航

左栏支持按项目分组或平铺任务，按最近更新或手动拖动排序。项目菜单提供项目操作，任务支持新建、重命名和归档；项目旁的新建加号常驻，悬停不替换项目图标。移除项目不删除目录或会话，归档任务只从活动列表隐藏。

点击项目图标或项目菜单中的对应入口打开紧凑选择面板，使用 Lucide 预设图标、预设颜色或自定义颜色。图标和颜色按项目保存为浏览器视图状态。分组折叠和视图选项同样保存在浏览器中；工作区收起再展开会恢复任务列表的默认截取长度。

新建时优先复用该项目的空任务；如果目标已有其他草稿，则创建新任务，避免覆盖。创建期间的输入先归入目标项目的新草稿，任务创建完成后转入该任务；先前任务的草稿独立保留。

Windows 目录选择使用系统文件夹窗口，打开时以前台窗口为 owner；取消不登记目录，选中后校验路径。原生窗口采用 PerMonitorV2 DPI 绘制。

## 主栏对话与阅读位置

主栏持续显示同一任务的对话。用户正文按原文呈现，助手 Markdown 支持行内和块级数学公式；思考、每次模型回复和每次工具调用按实际顺序保持独立身份。最终回答不折叠，消息本身不提供复制按钮；代码块保留复制代码操作。长消息折叠只计算正文中实际隐藏的行。

思考行从 `thinking` 标签开始，只有内容超出单行或包含后续行才显示展开箭头。展开后标签与正文首行同排，后续行使用整行宽度；连续空行在显示时合并为一次换行，持久化原文不变。

工具使用 `read`、`bash`、`edit` 等原名，类型图标固定在名称左侧，展开箭头位于名称后。工具开始事件立即生成条目，call/result 按共同 ID 合为同一项，进度在原位更新。每次工具调用直接逐项呈现，不增加批次折叠层；输入、输出和 diff 按实际内容展开。工具结果不提供复制按钮，输出标签与正文紧邻。

稳定历史与活动事件组成同一条时间线；执行结束后以持久历史替换活动投影。同样的输入在不同轮次中仍是独立消息，不按正文去重。主栏不显示通用诊断、请求错误或完成／失败终态行；工具自身失败留在工具结果，手动中断显示安静的“已停止”标记，其他错误在轨迹中查看。

滚动只有底部跟随与锚定阅读两种状态。处于底部时跟随流式更新；向上阅读后保存条目和偏移，重新触底才恢复跟随，不显示“回到最新”按钮或新增计数。展开、收起和内容收缩保持所操作条目的位置，不把程序恢复滚动当成用户改变阅读意图。

### 工具输出与差异

终端输出保留 ANSI 样式；读取结果显示源行号，搜索结果保留文件与行定位。成功的 edit/write 结果提供统一 diff，文件名和增删计数只在工具行显示一次。

差异卡片按文件语言高亮，使用单列源行号、红绿底色和左侧增删标记。删除行采用旧行号，新增和上下文行采用新行号；每个改动块保留前后各一行上下文，分段用窄分隔带连接，省略内容不改变源行号。卡片边缘为直角，增删标记保持垂直。代码使用系统等宽字体栈、13px 常规字重和 1.8 倍行高。

## 输入、排队与停止

输入框在运行中仍可编辑，不显示占位提示。模型未选定的空任务可以先选择模型，再发送保留的草稿。候选菜单打开时，Enter 优先选中候选；普通输入的行为如下：

| 操作 | 效果 |
| --- | --- |
| 空闲时发送或 Enter | 开始新一轮 |
| 运行中 Enter | 将本次输入排队，当前轮结束后继续 |
| 运行中 Ctrl/Cmd+Enter | 仅将本次输入作为插话送入当前轮 |
| 运行中输入为空时 Ctrl/Cmd+Enter | 依次提前发送全部排队消息 |
| Shift+Enter | 换行 |
| 停止按钮 | 取消当前执行或压缩，保留尚未消费的排队消息 |

队列位于输入框上方，多条时可折叠。每条提供编辑、删除和单击箭头提前发送；编辑用 Enter 保存、Escape 取消。提前发送会把同一条输入移入当前轮，空闲时启动新一轮；队列操作在服务端确认后更新。

普通失败已经保存终态时仍继续队列；中断或准备、终态保存失败时停止当前执行链，保留尚未执行的排队输入。

输入框提供文件和 Skills 候选，不提供通用命令或帮助菜单。左下角“＋”展开工具栏，设置、上下文压缩和主题入口共用该工具栏，不在侧栏重复设置入口。首次发送后自动展开一次，此后流式更新保留本次挂载期间的手动选择；自动触发、鼠标、键盘和 Escape 共用展开状态。

发送与停止使用同一个粉白球体控件；运行时发送位置显示停止按钮，排队和插话通过上述键盘操作完成。停止处理中按钮不可重复触发。

各任务草稿独立保存，切换任务不混用内容。草稿、主题、侧栏宽度和阅读锚点保存在浏览器本地存储；同源标签页同步草稿与视图。存储迁移与归约边界见 [数据位置](singularity.md#storage)和[前端视图](singularity.md#frontend)。

### Skills 候选

在光标所在词首输入 `/` 显示可手动使用的技能名称和说明，继续输入按名称前缀筛选。上下键移动，Enter、Tab 或鼠标选中，Escape 关闭。选中只填入 `/名称 `，保留后续文本与光标位置，不自动发送。

消息开头的 `/名称` 在发送后加载正文；行内斜线仍是普通文本。候选与发送沿用 DSH 的分工，自动加载机制见 [指令与技能](singularity.md#instructions)，技能安装见 [安装说明](INSTALL.md#skills)。

## 模型、上下文与设置

首次配置时，已有提供方显示缺失密钥输入，没有提供方时显示添加卡片，允许稍后配置。“设置 > 模型”维护 Provider 地址、协议、模型和只写 API Key；输入框右侧的组合选择器只管理当前任务的模型与思考程度。配置保存成功而密钥保存失败时，保留编辑内容和错误，可直接重试。

编辑或删除提供方后，失效的全局默认模型会重新选择；仅默认思考档位被移除时保留原模型，改用其默认行为。提供方删除已保存而密钥清理失败时明确报告部分完成，未来回合立即使用新的配置快照，仍可在确认框中重试清理。

模型选择器沿用 [dsh-reasoning-slider](https://github.com/qjcnmd/dsh-reasoning-slider) 0.0.4 的单面板布局：上部为模型列表，下部为英文推理等级滑条；没有搜索、快速模型或恢复默认按钮。选中模型后面板保持打开。滑条拖动时连续预览，松手提交最近档位；连续调档串行保存最后选择。保存队列按项目、任务和模型隔离，切换后丢弃旧队列中未提交的编辑，已经发出的请求仍归原任务。

模型弹层宽 220px，位于按钮上方 8px、向右偏移 30px，列表最高 200px，窄窗口限制在可用视口内。主题变量映射到本地设计变量，模型数据和保存操作由 Workbench Store 提供；改编来源的 MIT 声明保留在 `styles/model-picker.css`。

上下文圆环与压缩按钮合并，仅在空闲且已有历史时可执行；首次点击显示确认，再次点击开始压缩，点击外部或收起工具栏取消确认。按钮只保留自定义浮层和 `aria-label`，不叠加原生 title。悬停或聚焦时，仅在当前模型有真实输入用量和有效容量时显示三行居中提示：“上下文窗口：”“百分比已用”“已用标记，共容量”。

用量取当前模型最近一次有测量的请求，结束事件到达即可更新，不等待整轮结束。缓存输入已包含在输入量内，不重复相加，不累计历次请求或加上输出；下一请求尚无用量时保留上次测量，切换模型或压缩后清除，直到取得新测量。未知数据不显示提示。浮层使用 12px 文字、7px/11px 留白和 12px 圆角。

默认浅色，太阳／月亮切换深浅主题；设置中的消息字号即时作用于用户正文和模型最终回复，范围 12–24px，默认 16px，不改变思考、工具结果和输入框字号。主题与字号随浏览器视图保存，代码高亮跟随主题。

## 侧栏与轨迹

左右侧栏共用开合控件、分隔条规则和一个 220–420px 的宽度值；调整任一侧同时更新两侧，支持指针捕获拖动与键盘方向键。收起后零占位，仅保留展开按钮，不显示竖栏底板或顶部横条；右侧标题无底部分隔线。

右侧栏每次打开先显示仅含“轨迹”的选择首页，再进入紧凑记录表。列表支持逐轮、逐调用折叠，角色直接显示协议种类的英文名称；不提供顶栏统计、搜索、时间条或范围选择。选择记录后在同一面板显示详情，返回列表恢复阅读位置及触发按钮焦点；切换任务后查看对应任务的轨迹。

详情按对象提供正文、思考、输入输出、请求上下文、工具定义、选项、用量、时序和原始数据。请求详情按需加载，读取失败明确反馈并提供重试，记录本身损坏也会指出原因；不会因此隐藏核心会话历史。工具详情不提供复制完整记录按钮。

失败条目的样式和详情状态来自同一状态值。请求概览保留提供方、模型、耗时和错误分类；事件和工具错误在各自正文或输出中显示一次，不把同一正文再复制到错误字段。工具耗时来自执行器，历史缺少测量时显示未知，不用页面停留时间推算。

桌面侧栏与对话并排，窄窗口中的轨迹覆盖右侧工作区，可用关闭按钮或 Escape 返回。对话始终留在主栏，没有独立的全局 Details 面板。请求记录的持久化和隐私边界见 [请求观测与详情索引](singularity.md#requests)和[协议续接](singularity.md#provider)。

## 状态与错误反馈

侧栏绿点表示正常完成，红点表示失败或异常中断；它们只标记本次页面打开期间观察到的后台未读终态。打开任务即清除，当前任务与首次加载的历史任务不标记；集合只在内存中维护。手动停止根据当前轮接受的取消记录判定，不标红点。

运行任务的名称使用蓝粉紫扫光。主栏整轮执行显示小球和状态点，首字等待、工具执行和后续请求等待阶段都保留，15 秒后附带耗时，不显示底部请求统计。

断线保留草稿、禁用发送，不显示连接横幅，也不自动重放结果不确定的动作。一般动作错误短暂提示，表单和队列错误留在原位置；请求错误、活动诊断与当前终态错误在轨迹查看。

面向用户的校验和恢复提示使用中文，以“项目”“任务”“模型设置”指称对应界面。底层操作系统和提供方错误保留原始诊断，协议字段及技术标识不为界面翻译而改名。

## 视觉与动效

控件、列表行、菜单和页签采用圆角；差异卡片保留直角。用户消息浅色背景为 `#fbd6e7`、深色背景为 `#f077af`，均使用深色文字；输入框模型名称使用主题蓝色。工具与思考标签共用 16px、500 字重；thinking 和 read 使用右侧摘要同款灰色，其他工具使用蓝色。

thinking 文字与工具图标从同一左边缘开始，名称区仅预留最长常用标签所需的宽度，使展开箭头、分隔点和摘要起点对齐，思考行前不留图标空位。运行中的标签共用白色高光、100° 渐变和 0.7 秒扫光，完成后恢复纯色，不附加“运行中／进行中”文字。

| 对象 | 动效约定 |
| --- | --- |
| 侧栏 | 宽度、内容位移和显隐共用 280ms 缓入缓出；拖动时直接跟随指针 |
| 项目下的任务列表 | 高度展开／收起 360ms；任务条目共用 240ms 淡入和从上方 12px 移入，按索引间隔 50ms；关闭时随列表淡出收回 |
| 菜单与内容 | 菜单只做整体透明度淡入；思考和工具详情用高度展开，历史正文不重复播放入场 |
| 输入工具栏与队列 | 工具栏宽度／透明度共用 240ms；队列从输入框后方向上弹出，新增、展开和移除共用 240ms 高度与位移过渡 |
| 模型选择器 | 弹层无过渡；滑块拖动直接跟手，松手或键盘切档用 180ms 吸附，滑块与粉色填充条共用缓动，轨道底色为浅灰 |
| 轨迹 | 列表与详情、详情栏目通过 Motion 的 `AnimatePresence` 顺序过渡，折叠使用布局位移动画 |
| 主题 | 支持同文档 View Transition 时使用 220ms 淡变 |

发送／停止球体为 28px，空闲流动与光照周期分别为 4.8 秒、3.6 秒，执行或悬停时为 1.4 秒、1.05 秒。主栏运行指示复用同一组件与动画规则，缩为 12px 快速流动球；后接与球体底部对齐的 4px 固定粉白状态点，每秒按一至三个点循环，预留固定宽度防止计时位移。

减少动态效果时，扫光、球体和状态点静止，展开、切换与吸附直接到位。动画仅属于展示，不参与请求、工具或记录状态。
