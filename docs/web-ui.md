# 工作台交互

本文维护当前界面的操作、显示与交互约定。配置和初次使用见 [安装说明](INSTALL.md)，持久事实、协议和状态所有权见 [架构图谱](architecture.md)。

## 项目与任务导航

新任务输入框上方的项目选择从按钮上方向上展开选项，输入框保持原位，复用左侧项目会话的高度展开组件和箭头；选择后收起并进入对应项目的新任务。

左栏固定按项目分组，组内任务按最近更新排序。空项目下不显示占位入口；空白会话是尚未命名、没有回合及回合终态的会话，仅显示当前选中的一条，其他已有会话和执行中的任务正常显示。新建操作可复用空闲的空白会话，已命名任务保留独立身份。项目与任务默认透明、无边框和分隔线，悬停显示圆角底色，当前任务保留选中底色。项目菜单提供项目操作，任务支持新建、重命名和归档；项目旁的新建加号常驻，悬停不替换项目图标。移除项目不删除目录或会话，归档任务只从活动列表隐藏。

点击项目图标或项目菜单中的对应入口打开紧凑选择面板，使用 Lucide 预设图标、预设颜色或自定义颜色。图标和颜色按项目保存为浏览器视图状态。分组折叠和视图选项同样保存在浏览器中；工作区收起再展开会恢复任务列表的默认截取长度。

点击项目新建会自动展开该分组并显示新任务。点击新建即建立空任务，不等待首次发送；优先复用该项目的空任务，如果目标已有其他草稿，则创建新任务，避免覆盖。创建期间的输入先归入目标项目的新草稿，任务创建完成后转入该任务；先前任务的草稿独立保留。

Windows 目录选择使用系统文件夹窗口，打开时以前台窗口为 owner；取消不登记目录，选中后校验路径。原生窗口采用 PerMonitorV2 DPI 绘制。

## 主栏对话与阅读位置

新任务页面顶部与内容区使用同一底色，不显示空标题栏。主栏持续显示同一任务的对话。用户正文按原文呈现，助手 Markdown 支持行内和块级数学公式；思考、每次模型回复和每次工具调用按实际顺序保持独立身份。最终回答不折叠，消息本身不提供复制按钮；代码块保留复制代码操作。长消息折叠只计算正文中实际隐藏的行。

思考行从 `thinking` 标签开始，只有内容超出单行或包含后续行才显示展开箭头。展开后标签与正文首行同排，后续行使用整行宽度；连续空行在显示时合并为一次换行，持久化原文不变。

工具使用 `read`、`bash`、`edit` 等原名，类型图标固定在名称左侧，失败时替换为红色错误图标，展开箭头位于名称后。工具开始事件立即生成条目，call/result 按共同 ID 合为同一项，进度在原位更新。每次工具调用直接逐项呈现，不增加批次折叠层；输入、输出和 diff 按实际内容展开。工具结果不提供复制按钮，输出标签与正文紧邻。Bash 折叠摘要显示模型随调用提供的简短操作描述；没有描述的历史调用回退显示命令。文件工具的折叠摘要优先显示项目相对路径，项目外、系统用户主目录内的路径缩写为 `~/…`，其他路径保持原样。完整命令和路径保留在展开详情中。失败状态通过图标、颜色和无障碍标签表达，不额外重复“失败”文字。失败折叠行只显示简短原因，例如 No such file or directory 或“执行超时”；异常类型、错误编号、路径和堆栈放在展开详情中。无法提取简短原因时提示展开查看，完整结果始终保留。

稳定历史与活动事件组成同一条时间线；执行结束后以持久历史替换活动投影。同样的输入在不同轮次中仍是独立消息，不按正文去重。主栏不显示通用诊断、请求错误或完成／失败终态行；工具自身失败留在工具结果，手动中断显示安静的“已停止”标记，其他错误在轨迹中查看，请求错误同时显示它的稳定诊断码。助手与思考片段的状态来自产出它的那次请求：请求失败或取消时片段显示同一终态（实时与历史一致），请求成功或仍在进行时不覆盖片段自己的结果。本次停止提示只看时间线尾部：历史上更早的中断记录不再遮蔽它，尾部紧邻已有停止提示时合并为同一条。

滚动只有底部跟随与锚定阅读两种状态。处于底部时跟随流式更新；向上阅读后保存条目和偏移，重新触底才恢复跟随，不显示“回到最新”按钮或新增计数。展开、收起和内容收缩保持所操作条目的位置，不把程序恢复滚动当成用户改变阅读意图。

### 工具输出与差异

终端输出保留 ANSI 样式；读取结果按读取时记录的真实源范围显示行号（起始行与正文行数来自工具执行，分页与超长行说明不计入），搜索结果保留文件与行定位。没有这份来源信息的旧记录按普通文本展示，不猜正文与说明的边界。成功的 edit/write 结果提供统一 diff，文件名和增删计数只在工具行显示一次。

差异卡片按文件语言高亮，使用单列源行号、红绿底色和左侧增删标记。删除行采用旧行号，新增和上下文行采用新行号；每个改动块保留前后各一行上下文，分段用窄分隔带连接，省略内容不改变源行号。卡片边缘为直角，增删标记保持垂直。代码使用系统等宽字体栈、13px 常规字重和 1.8 倍行高。

## 输入、排队与停止

空任务将标题、项目选择器和输入框作为一组居中显示；出现对话后，输入框悬浮在主栏底部。输入框在运行中仍可编辑，不显示占位提示。模型未选定的空任务可以先选择模型，再发送保留的草稿。候选菜单打开时，Enter 优先选中候选；普通输入的行为如下：

| 操作 | 效果 |
| --- | --- |
| 空闲时发送或 Enter | 开始新一轮 |
| 运行中 Enter | 将本次输入排队，当前轮结束后继续 |
| 运行中 Ctrl/Cmd+Enter | 仅将本次输入作为插话送入当前轮 |
| 运行中输入为空时 Ctrl/Cmd+Enter | 一次提交全部排队消息，提前发送 |
| Shift+Enter | 换行 |
| 停止按钮 | 取消当前执行或压缩，保留尚未消费的排队消息 |

队列位于输入框上方，多条时可折叠。每条提供编辑、删除和单击箭头提前发送；编辑用 Enter 保存、Escape 取消。提前发送会把同一条输入移入当前轮，空闲时启动新一轮；整批提交由服务端在同一份队列状态内定位、注入并移除，页面不按自己的快照逐条请求，因此新快照不会让某条漏发或重复发送。队列操作在服务端确认后更新。队列展示的是当前仍待执行的输入全集：除排队的 follow-up 外，也包括失败边界归还未消费的插话，两者提供同一组操作。

普通失败已经保存终态时仍继续队列；中断或准备、终态保存失败时停止当前执行链，保留尚未执行的排队输入，直到程序退出。程序重启只恢复已保存的对话，不恢复队列。

输入框提供文件和 Skills 候选，不提供通用命令或帮助菜单。左下角“＋”从原位置向上、向右变形成三行菜单，依次为上下文压缩、主题切换（按钮标签为“深色模式／浅色模式”）和设置。菜单展开尺寸为 172×172px，三行各 48px。上下文圆环可点击查看用量，右侧压缩按钮保留二次确认；主题与设置的左侧图标仅展示，右侧文字按钮触发操作。点击外部、焦点离开或按 Escape 收起菜单。菜单通过“＋”按钮手动展开，发送消息与流式更新保留当前展开状态；鼠标、键盘和 Escape 共用展开状态。

发送与停止使用同一个球体控件，浅色模式为粉白玻璃，深色模式为 Galaxy Orb 银河玻璃球；运行时发送位置显示停止按钮，排队和插话通过上述键盘操作完成。停止处理中按钮不可重复触发。

各任务草稿独立保存，切换任务不混用内容。草稿、主题、侧栏宽度和阅读锚点保存在浏览器本地存储；按单页面使用维护状态，刷新后恢复已保存的草稿与视图。存储与归约边界见 [数据位置](architecture.md#storage)和[前端视图](architecture.md#frontend)。

### Skills 候选

在光标所在词首输入 `/` 显示可手动使用的技能名称和说明，继续输入按名称前缀筛选。上下键移动，Enter、Tab 或鼠标选中，Escape 关闭。选中只填入 `/名称 `，保留后续文本与光标位置，不自动发送。

消息开头的 `/名称` 在发送后加载正文；行内斜线仍是普通文本。候选只负责填入名称，正文由发送环节加载，自动加载机制见 [指令与技能](architecture.md#instructions)，技能安装见 [安装说明](INSTALL.md#skills)。

## 模型、上下文与设置

首次配置时，已有提供方显示缺失密钥输入，没有提供方时直接显示自定义配置表单，允许稍后配置。提供方标题行可点击展开配置，展开与收起复用项目会话列表的高度过渡及箭头；删除是独立操作。“设置 > 模型”通过单一“添加提供方”入口填写自定义 ID、名称、地址、协议和只写 API Key；模型使用独立添加／编辑窗口，填写模型 ID、显示名称、上下文窗口和最大输出容量，高级配置可修改该模型协议。一次保存包含配置与本次填写的新密钥，未填写时保留已有密钥。输入框右侧的组合选择器只管理当前任务的模型与思考程度。配置保存成功而密钥保存失败时，保留编辑内容和错误，可直接重试。模型发现区分配置／认证错误与网络、限流、过载或无效目录；前者引导修正地址或密钥，后者允许稍后重试，二者均保留手动添加模型的入口。提供方目录响应超过 32 MiB 时明确报错，公共元数据目录超限时只跳过补齐。

编辑或删除提供方后，失效的全局默认模型会重新选择；仅默认思考档位被移除时保留原模型，改用其默认行为。提供方删除已保存而密钥清理失败时明确报告部分完成，未来回合立即使用新的配置快照，仍可在确认框中重试清理。

模型选择器采用单面板布局：上部为模型列表，下部为推理等级滑条；没有搜索、快速模型或恢复默认按钮。选中模型后面板保持打开。任务保留的推理等级从配置移除时，选择器标明不可用并提示重新选择模型，不将滑条落在其他等级上冒充当前选择。滑条拖动时连续预览，松手提交最近档位；连续调档串行保存最后选择。保存队列按项目、任务和模型隔离，切换后丢弃旧队列中未提交的编辑，已经发出的请求仍归原任务。

模型弹层复用项目选择的 Accordion 高度展开与内容淡入，宽 220px，位于按钮上方 8px、向右偏移 30px，列表最高 200px，窄窗口限制在可用视口内。主题变量映射到本地设计变量，模型数据和保存操作由 AppStore 提供。

上下文圆环位于压缩文字按钮左侧，点击展开用量浮层；压缩操作由右侧按钮触发，仅在空闲且已有历史时可执行；首次点击显示确认，再次点击开始压缩，点击外部或收起工具栏取消确认。按钮只保留自定义浮层和 `aria-label`，不叠加原生 title。点击圆环后，当前模型有真实输入用量和有效容量时显示三行居中提示：“上下文窗口：”“百分比已用”“已用 token，共容量”。

用量取当前模型最近一次有测量的请求，结束事件到达即可更新，不等待整轮结束。缓存输入已包含在输入量内，不重复相加，不累计历次请求或加上输出；下一请求尚无用量时保留上次测量，切换模型或压缩后清除，直到取得新测量。容量来自会话快照中当前执行（或最近一次执行）冻结的有效上下文窗口，不随模型目录的后续编辑改变；窗口不可知时保留未知，不回退猜测。未知数据提示“暂无上下文用量”。浮层使用 12px 文字、7px/11px 留白和 12px 圆角。

输入框下方常显会话累计用量统计条，与输入框同宽同轴并居中：先 TPS，再累计 token 与缓存命中率，数值不带“平均”“累计”前缀。它与上下文圆环是两个数，不合并：圆环是当前占用，累计只增不减。累计 token 优先采用供应商有效总量，未记录总量的旧请求按输入加输出计算，缓存命中部分不重复相加。缓存命中率的分母是输入（不含输出），没有输入或任一请求未报告缓存用量时不显示。TPS 为具有有效计时记录的请求的输出 token 合计除以生成耗时合计，生成耗时从首个正文、思考或工具调用增量到请求完成，不含首 token 等待和工具执行时间；旧请求未记录生成耗时则不参与 TPS，没有有效样本时不显示。合计由服务端按整份账本一次算出并随会话摘要下发，运行中回合的增量由活动事件在同一规则下补齐——回合开始时冻结的历史快照不含该回合之后落盘的记录，两者相加既不重复也不会漏掉更早的回合；结算后的下一次读取把该回合并入快照。没有任何请求报告 usage 时整条不显示，存在未报告 usage 的请求时累计带“≥”并在悬停说明中标注为下界。读数使用 12px 文字、等宽数字与整圆底色，内容过长时按容器裁切。

默认浅色，太阳／月亮切换深浅主题；设置中的消息字号采用紧凑数字输入与上下箭头调节，即时作用于用户正文和模型最终回复，范围 12–24px，默认 16px，不改变思考、工具结果和输入框字号。主题与字号随浏览器视图保存，代码高亮跟随主题。

## 侧栏与轨迹

左右侧栏共用开合控件、分隔条规则和一个 220–420px 的宽度值；调整任一侧同时更新两侧，支持指针捕获拖动与键盘方向键。收起后零占位，仅保留展开按钮，不显示竖栏底板或顶部横条；右侧标题无底部分隔线。

右侧栏每次打开先显示仅含“轨迹”的选择首页，再进入紧凑记录表。列表支持逐轮、逐调用折叠，角色直接显示协议种类的英文名称；不提供顶栏统计、搜索、时间条或范围选择。选择记录后在同一面板显示详情，返回列表恢复阅读位置及触发按钮焦点；切换任务后查看对应任务的轨迹。

详情按对象提供正文、思考、输入输出、Harness 指令及变化、工具定义、请求选项、用量、时序和原始数据。指令详情标出 System / Developer 角色。原始数据直接序列化该对象本身：请求观测已包含 requestHead，不再附加指向同一对象的别名。请求只记录 Harness 指令与工具定义的快照引用，不另存或提供每次请求的完整对话上下文。定义记录损坏时明确提示，核心会话历史仍可阅读。工具详情不提供复制完整记录按钮。

请求重试前清空本次临时正文和思考，保留失败请求的观测记录；最终失败或手动停止时保留中断内容供查看，刷新后仍可见，但这些内容不进入后续模型上下文。

失败条目的样式和详情状态来自同一状态值。请求概览保留提供方、模型、耗时和错误分类；事件和工具错误在各自正文或输出中显示一次，不把同一正文再复制到错误字段。工具耗时来自执行器，历史缺少测量时显示未知，不用页面停留时间推算。

桌面侧栏与对话并排，窄窗口中的轨迹覆盖右侧工作区，可用关闭按钮或 Escape 返回。轨迹关闭时暂停接收会话视图更新；再次打开仍先进入侧栏选择页，进入轨迹后直接读取当前快照。对话始终留在主栏，没有独立的全局 Details 面板。请求记录的持久化和隐私边界见 [请求观测与详情索引](architecture.md#requests)和[协议续接](architecture.md#provider)。

## 状态与错误反馈

侧栏绿点表示正常完成，红点表示失败或异常中断；它们只标记本次页面打开期间观察到的后台未读终态。打开任务即清除，当前任务与首次加载的历史任务不标记；集合只在内存中维护。手动停止根据当前轮接受的取消记录判定，不标红点。

运行任务的名称使用灰色明暗扫光。主栏整轮执行显示小球和状态点，首字等待、工具执行和后续请求等待阶段都保留，15 秒后附带耗时，不显示底部请求统计。

断线保留草稿、禁用发送，不显示连接横幅，也不自动重放结果不确定的动作；重连后的基线同步（bootstrap 与当前任务读取）收敛前同样禁用发送，就绪以会话快照可信为准。一般动作错误短暂提示，表单和队列错误留在原位置；请求错误、活动诊断与当前终态错误在轨迹查看。手动压缩在对话区占一行状态：进行中显示“正在压缩…”，结束后显示这次压缩的结果（没有可压缩的内容、已停止或失败原因），成功时该行就是历史里的压缩摘要条目；压缩与停止阶段主栏底部另有英文阶段行（“compacting…”／“stopping…”）。任务状态只跟随回合终态，压缩失败或中断不把任务标红；轨迹中的独立压缩错误标为“压缩失败”，保留具体原因。

面向用户的校验和恢复提示使用中文，以“项目”“任务”“模型设置”指称对应界面。底层操作系统和提供方错误保留原始诊断，协议字段及技术标识不为界面翻译而改名。

## 视觉与动效

界面采用中性灰白风格：浅色为白色画布与白色内容表面，深色为 `#191919` 画布与 `#242424` 内容表面。左右侧栏和正文代码块与输入框共用背景色（浅色 `#ffffff`、深色 `#2f2f2f`）；输入框和代码块使用相同的细描边，左右侧栏与主栏之间使用同色细分界线；标题直接落在背景左上角，不设独立横条、底色与边框，正文从它下方穿过，输入区按实际高度占位，对话在其上方独立滚动，末尾内容与运行指示始终留有间距。侧栏项目与任务直接排列，行背景仅用于悬停和任务选中反馈，悬停底色比选中底色更淡；悬浮菜单、弹层、候选与提示使用实色表面加边框与轻阴影。强调色统一为品牌粉（浅色 `#db2777`、深色 `#f472b6`），用于链接、主按钮、选中态、焦点与运行扫光；状态色使用绿 `#34c759`、红 `#ff3b30`。

控件、列表行、菜单和页签采用圆角，按钮按下即时缩放反馈；差异卡片保留直角。用户消息浅色背景为 `#fbd6e7`、深色背景为 `#f077af`，均使用深色文字；输入框模型名称使用主题粉色。思考、工具和压缩等可展开条目的标题行在悬停、按下和展开时保持透明背景，键盘焦点保留可见提示。工具与思考标签共用 16px、500 字重；thinking 和 read 使用右侧摘要同款灰色，其他工具使用主题粉色。

助手正文行高 1.6、段间距 10px、标题随消息字号按 1.625／1.375／1.25 倍缩放（默认 16px 时为 26／22／20px）且上间距 20px；用户消息气泡行高 1.5、段间距 0；工具输出等非消息正文的标题为 17–22px。执行日志行本身 24px 高、彼此只留 6px，正文消息在行距之外再多 5px——日志比正文更密，页面整体按这个层级控制空白。

thinking 文字与工具图标从同一左边缘开始，名称区仅预留最长常用标签所需的宽度，使展开箭头、分隔点和摘要起点对齐，思考行前不留图标空位。运行中的标签共用白色高光、100° 渐变和 0.7 秒扫光，完成后恢复纯色；可见文字不附加“运行中／进行中”，状态文本只出现在屏幕阅读器标签里。

| 对象 | 动效约定 |
| --- | --- |
| 侧栏 | 宽度、内容位移和显隐共用 280ms 缓入缓出；拖动时直接跟随指针 |
| 项目下的任务列表 | 高度展开 250ms、收起 200ms，内容同步淡入并去模糊 2px，项目行箭头同步上下翻转；任务条目随列表一起显现，不各自播放入场 |
| 菜单与内容 | 上下文菜单做整体透明度淡入；思考和工具详情沿用同一高度展开规则，历史正文不重复播放入场 |
| 输入工具栏与队列 | 工具菜单由圆形按钮变形成圆角面板，展开 350ms、收起 250ms，内容以 200ms 淡入淡出；队列从输入框后方向上弹出，新增、展开和移除共用同一组高度与位移过渡（展开 250ms、收起 200ms） |
| 模型选择器 | 弹层复用高度展开（展开 250ms、收起 200ms）；滑块拖动直接跟手，松手或键盘切档用 180ms 吸附，滑块与粉色填充条共用缓动，轨道底色为浅灰 |
| 轨迹 | 列表与详情、详情栏目通过 Motion 的 `AnimatePresence` 顺序过渡，折叠使用布局位移动画 |
| 主题 | 支持同文档 View Transition 时使用 220ms 淡变 |

输入文字保持 16px，输入框的留白与控件尺寸维持原有比例，不随日志密度调整；发送／停止球体为 34px。深色使用 [VoiceOrbs Galaxy Orb](https://voiceorbs.vercel.app/orbs/galaxy-orb) 的 Canvas 星场、银河、玻璃高光和彩色边缘，保留原版 Thinking 外观和单向旋转，配色为青色到紫红色。空闲速度为网页标准速度的 6×，执行或悬停为 18×（正常状态的 3 倍）；按累计时间推进，切换速度保持当前位置。改编源码的 MIT 声明保留在 `src/components/galaxyRenderer.ts`。

浅色球体采用透明玻璃外壳、交叠的粉白花瓣光带与明亮中心；与深色球体共用累计时间和 6×／18× 速度规则，悬停或执行加速保持运动位置连续。主栏运行指示复用浅色球体组件与动画规则，缩为 12px 快速流动球；后接与球体底部对齐的 4px 固定粉白状态点，每秒按一至三个点循环，预留固定宽度防止计时位移。

减少动态效果时，扫光与球体静止，展开、切换与吸附直接到位；状态点仍按秒推进。动画仅属于展示，不参与请求、工具或记录状态。

项目选择按钮按当前项目名称自然排布，箭头紧随名称；上方选项面板按“添加项目”四字、图标、勾选位及留白确定紧凑宽度，所有选项的图标和文字对齐，过长项目名称省略显示。模型选择向上展开，采用 Accordion 的高度过渡（展开 250ms、收起 200ms）、透明度与去模糊过渡，箭头上下翻转。浅色球体使用粉白色核心、透光花瓣与粉白外缘。

同类高度展开控件默认复用 Disclosure 与 ExpandChevron，共用同一组高度时序（展开 250ms、收起 200ms）、淡入去模糊和箭头翻转；项目与模型浮层共用随当前可见高度绘制的面板外观；底色与边缘保持不透明，仅内部内容执行淡入和去模糊，避免透出后方输入框。模型发现目前通过“获取可用模型”手动触发，可读取思考档位及容量并补充目录元数据；尚不具备按字段持续同步推荐配置的智能配置模式。采纳规则由 `src/modelImport.ts` 一处维护：新模型按目录值新建并采用表单协议；已有行只补空缺，显示名称、容量、思考词形与输出上限字段都保留用户写过的值，推理变体按 id 或 wire effort 合并而不是替换，关闭档位与自定义档位在导入后仍在，默认档位只要仍在合并结果里就不变。
