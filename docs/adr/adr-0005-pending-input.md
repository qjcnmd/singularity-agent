# 会话 steer 输入箱

日期：2026-10-11。状态：已采用。

## 决策

主输入框统一编辑文字、图片和 Skill 引用。空闲时发送启动新回合，运行中发送作为 steer 引导当前回合；一次执行预订只执行一个回合。

Conversation 持有会话级 `SteeringInbox`。接受输入和分配序号在同一状态锁内完成，输入依次加入箱子。活动执行在下一次模型请求前逐条保存引导，保存成功后才确认移除。steer 不改变已经发出的模型请求，也不打断当前工具批次。

每条输入在接受时分配固定的消息身份。追加失败后重开日志若已恢复该消息，继续执行只确认消费，不重复保存或发布。输入保存或当前请求失败会结束执行，尚未消费的 steer 保持原位；继续会话时先消费较早接受的 steer，再纳入新提交。用户明确停止取消当前未消费的 steer，已经保存的消息仍在历史中。

普通提交等待输入保存成功后返回；steer 在进入内存输入箱后返回。前端仅在成功且草稿未继续编辑时清空输入，失败保留草稿。

## 依据与边界

运行中补充消息用于引导当前任务，按模型请求边界交付可保持消息和工具调用的完整性。输入箱只负责接受顺序与可靠交付，不主动启动新的执行。

待处理输入只在进程内存在，重启后由用户手动继续已保存历史，遵循[宪章](../constitution.md#运行边界)。如果未来需要重启后继续未消费输入，必须重新评估输入接受与持久化的边界；内存箱不能承担该保证。
