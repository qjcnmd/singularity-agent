# 上下文摘要、指令刷新与请求记录

日期：2026-10-11。状态：已采用。

## 决策

手动、自动压缩和上下文溢出恢复共用摘要过程：对较早历史生成摘要，保留近期消息，并保持工具调用与结果完整配对。摘要请求沿用历史正文；成功保存摘要与保留边界后，模型视图由摘要和近期历史组成。原始消息与图片快照不随上下文缩减删除，公开历史仍可查看原内容。

AGENTS.md 与 Skill 目录在每个普通回合开始及执行中的压缩后重新读取，文件修改在下一次读取后生效。MCP 工具和服务器说明在相同刷新边界接纳当前配置。文件指令是对话历史之前的请求前缀，Skill 正文由模型通过 `read` 按需读取并保存为普通工具结果；Skills 同时保留手动入口。

独立压缩复用最近请求保存的完整指令和工具定义，没有请求快照时才从当前配置准备。压缩结束后等待下一次输入；下一普通回合读取当前文件指令、技能与工具目录。

轨迹保留 Harness 指令及变化、工具定义、回答、工具输入输出、请求选项、错误和用量。指令前缀与工具定义作为请求定义快照保存，每次尝试引用对应定义并记录实际结果；不记录或提供每次请求完整上下文的额外副本。原始会话事实、模型视图与公开展示分别在自己的边界维护。

## 理由与取舍

摘要缩减模型输入，同时保留原历史供用户阅读和任务恢复。摘要前保持正文原样，避免额外改写破坏可复用的请求前缀；缓存是否命中仍由实际提供方决定。

回合开始和压缩后的文件读取让执行接纳当前指令；已经发出的请求使用自己的材料。独立压缩沿用最近请求定义，使摘要与此前执行使用相同的指令和工具，而下一回合自然接纳配置变化。

请求定义与尝试记录足以支持指令、工具、选项和错误的查看；每次保存完整上下文还会重复持久化大量对话内容。需要改变摘要方式或请求记录范围时，按实际模型输入、用户查看用途和存储成本重新评估。
