# Triage Labels

| Canonical role | Label in this repository | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚需评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到上述角色时，使用表中对应的实际标签。

完整标签体系（类型、优先级、状态、可执行性与阻断）、生命周期与使用规则见 `docs/agents/issue-tracker.md`；本表只定义 triage 角色到实际标签的映射，两者必须保持一致。
